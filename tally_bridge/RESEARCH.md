# BizAnalyst feature research

Reviewed 19 October 2026. The BizAnalyst website and Tally's official documentation host were blocked by this development environment's destination policy. Their domains were added to the cloud configuration draft; saving that draft does not apply it. The research below uses separately published, publicly accessible GitHub documentation. No third-party implementation code was copied.

BizAnalyst documentation in the `siliconveins/bizanalystdocs` repository is dated **2017**. It supports historical feature comparisons, not claims about today's prices, plans, feature availability or Tally Prime compatibility.

| Documented capability | Application to Vriddhi Fuels |
|---|---|
| [Configurable sync and separate deleted-voucher checks](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/desktop/settings/sync-configuration.md) | Incremental voucher/master reads, a separate complete deletion scan, and explicit offline timestamps. Historical BizAnalyst defaults were 5 minutes / 24 hours; this bridge targets 5 seconds / 1 hour. |
| [Day book](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/day-book.md), [ledger report](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/ledger-report.md), [profit & loss](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/profit-and-loss.md) | Native report requests and cached results inside the Tally app. |
| [Receivables](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/screens/receivable.md), [payables](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/screens/payable.md), [cash/bank](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/screens/cash-bank-balance.md) | Corresponding native report selections, without calculating balances from a partial sales-only feed. |
| [Items](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/screens/items.md), [pending sales orders](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/pending-sales-order.md) | Stock master/summary access and all voucher-type mirroring. A dedicated order-fulfilment UI is future work. |
| [Inactive customers](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/inactive-customers.md), [inactive items](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/inactive-items.md), [top reports](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/reports/top-report.md) | Useful next features: lost-customer follow-up, slow-moving stock, customer/product trends. These are not implemented in this bridge release. |
| [Report sharing and PDF preview](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/settings/share.md) | Sanitized report downloads, browser Print / Save as PDF, and the existing customer invoice PDF/Word workflows. No automatic customer messages. |
| [User permissions](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/faqs/manage-permissions.md) | A future role-based access upgrade. This release preserves the existing app's equal employee access. |
| [Subscription purchase](https://github.com/siliconveins/bizanalystdocs/blob/master/site/content/android/faqs/purchase-subscription.md) | Historical documentation confirms a paid subscription model; current prices and tier-specific features could not be verified. No current price or discount is asserted. |

For XML protocol cross-checking, consulted the [TallyConnector documentation](https://github.com/Accounting-Companion/TallyConnector/blob/master/docs/Readme.md), its published request models and synthetic XML fixtures. These are secondary sources and do not replace testing with the installed Tally Prime version. The sales XML itself comes from this repository's existing, business-specific `tally/index.html` exporter and is covered by semantic parity tests.
