🛢️

PAD statement PDF (+ invoice PDFs) → journals and fuel purchases.
💳

Fleet → Tally

XtraPower fleet-card and TDS sheets → settlement journals.
Private by design. These are the same tools as on the Mac, running entirely inside this browser — statements, PADs and invoices are read on this device and never uploaded. Download the XML and import it in Tally (Gateway → Import → Vouchers).
Mappings & settings are saved in this browser on this device. Use ⬇ Backup / ⇪ Restore in any tool to carry them to another device — Restore also accepts a data.json from the Mac app.
The first visit downloads the engine (about 15 MB; the IOCL tool adds a 17 MB PDF reader); after that it's cached.
